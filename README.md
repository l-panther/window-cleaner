# Window Cleaner Website

## Description
This project is a window cleaning service website built using Astro. It provides information about services offered, and contact details, allowing customers to easily learn about the business and request services.

## Features
- Service listings with descriptions  
- Responsive and accessible user interface  
- Fast performance using Astro static site generation  
- Clean and maintainable code structure  

## Installation
To run the project locally:

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```

## Usage
- Access the development server at `http://localhost:3000`  
- Navigate through the website to view services and information  
- Build the project for production:

```bash
npm run build
```

## Configuration
No additional configuration is required. Content can be updated within the source files.
